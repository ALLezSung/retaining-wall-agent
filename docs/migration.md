## 边界问题处置

- 删除不可达的强制确认表单，不新增确认门禁。
- 明确保留对话要求显式提供 q 的约定；独立算法仍允许 q 缺省为 0。
- 必须处理：有效参数变化清空结果及候选；同轮先计算后改参不返回过期成果；候选显示编号与选用一致；选用后墙型与实际几何一致。
- 保持原搜索算法及候选几何。原矩形案例的搜索可探索梯形；选用时更新墙型标记，避免后续参数修改又被错误地按矩形处理。限定矩形搜索是单独的业务改进，本轮不增加。
- 暂缓：工况程序化拦截、跨轮尺寸锁定、全文规范检索及新工程验算。尺寸锁定保留原本轮识别方式。
- 不新增聊天保存工具；保存仍通过网页业务入口完成。

## 最终结构与验证（2026-10-25）

- 模型适配：`src/llm`；通用工具循环与 skill 目录：`src/agent`；设计会话及装配：`src/design_agent`；界面：`src/webui`。
- 领域实现已全部归入 `src/skills/retaining_wall` 和 `src/skills/standards`。首轮迁移保留了顶层兼容导入；后续清理已删除这些文件，见下文。
- 固定注册 10 项工具；两个 skill 仅按需读取正文。临时 context 靠近本轮输入，不保存到历史；历史保留 assistant/tool 完整配对。
- 删除不可达确认表单；不新增强制确认步骤。无效输入不更新权威参数；同值参数更新保留结果，有效变化清除结果和候选。
- 在工具边界统一候选连续编号；选用后按实际 B/t 更新墙型。原二维搜索、固定底宽搜索与单独底宽比选的几何结果保持原样。
- 案例库关闭连接时显式释放资源，避免 Windows 文件占用；数据库路径、表结构和已有数据格式不变。
