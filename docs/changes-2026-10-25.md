# 本次聊天与项目变更汇总（2026-10-25）

本次工作将原来等待模型整段返回、聊天仅保存在内存中的 Streamlit 智能体，改为可实时展示执行进度、恢复设计会话并清晰区分过程与结论的设计工作台。保留模型层、通用运行层、设计业务层和网页交互层，确定性计算与原几何搜索基准保持一致。

## 最终交互与渲染

- 模型正文采用真实 SSE 流式输出，加载区展示当前 Run、执行阶段和已完成工具。
- 中间 Run 说明与最终回答以 `run_messages`、`content` 分开传递和保存，保留完整的模型工具历史。
- 当前尚未分类的文字从首字起进入正常正文槽；只有 `model_finished` 确认存在工具调用后，才移入灰色、小字号的无序列表，每个 Run 只归类一次。
- 列表槽、正文槽和状态槽独立且稳定。最终确认不重建正文布局；`message_completed` 只更新最终内容，包含轮次上限提示；流式中断保留已输出片段并显示中断说明。
- 成果收拢为“计算书”和“系统状态”两张卡片。计算书包含参数、背景、逐项计算、基底压力、规范覆盖与补充资料，以及 JSON/Markdown 下载；系统状态展示执行事件与工具记录。
- 侧栏按新建对话、载入对话、规范加载、教学案例库排列。标题原位编辑，左侧按钮载入，当前会话高亮，历史列表可滚动浏览全部记录。
- 模型下拉框和思考深度滑块分两行固定在侧栏底部，桌面与手机宽度均作布局检查。

## 模型与运行边界

- 增加兼容 OpenAI Chat Completions 的适配器，支持认证 `/models` 发现、流式文本和工具参数分片拼接、模型选择与思考深度映射。
- 优先采用服务声明的能力；未知模型保留默认设置，可在配置中覆盖思考深度值映射。保留旧 DeepSeek 适配器入口与环境变量兼容。
- 工具名称、参数和完成标记检查通过后才执行工具，处理断流、截断、传输错误及无效响应。
- 修复 Run 7 异常：达到工具轮次上限后，保留工具定义并显式设置 `tool_choice=none`，只汇总已有证据；状态标记为达到上限、可继续执行。
- 在适配器中拦截跨流式分片的原始 DSML 工具标记，不将正文中的标记当作已执行工具，也不反向解析后执行。旧异常历史在对外映射时标明未执行，保留原始记录。
- 技能说明明确：改参后必须重算；获准连续试算时可以在同一模型轮次依次改参、计算，减少轮次消耗。

## 会话持久化与依赖方向

- 应用定义 `ConversationStore` 存储接口，由 SQLite 实现，`bootstrap.py` 组合根负责注入模型与持久化适配器。
- 默认独立保存聊天数据库，原教学案例库继续使用原数据结构。原子保存消息、参数及来源、墙型、当前结果、候选、所选规范、模型历史和已读技能等状态。
- 新建会话先作为内存草稿，默认标题为北京时间。首次发送消息后才保存；仅改名、换模型/规范、载入教学参数不会创建空聊天记录。
- 已保存的聊天支持恢复、原位改名和删除；标题更新只改元数据，不修改聊天内容或排序时间。
- 保存失败可重试，已有交互内容仍在内存中；新建和切换会话不会覆盖尚未保存成功的聊天。
- 所选规范进入核算要求与报告；修改选择会使当前结果及候选失效，历史计算书保留生成时的状态。

## 配置、依赖与范围

- 补充通用 `LLM_*` 环境变量、思考映射和聊天数据库路径配置，保留旧 `DEEPSEEK_*` 用法。
- 配置模板推荐 `max_tokens=4096`、`max_rounds=10`；内置兼容默认值仍为 1200/6。项目使用浅色主题，Streamlit 最低版本为 1.41。
- 当前传输面向兼容 Chat Completions 且支持工具调用的模型服务。供应商未声明的能力不做付费探测，实际服务行为仍需根据端点验证。
- 现有比选只按教学抗滑、抗倾覆和基底全接触筛选；自定义压力上限等额外条件需由真实计算结果逐项核查。
- 保留既有教学计算范围；未实现的规范项目仍列为待补充资料或待验算，不新增完整工程合规结论。
