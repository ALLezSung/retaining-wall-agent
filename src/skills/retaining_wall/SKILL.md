# 重力式挡土墙教学初算

首次开展本业务先读取本说明。参数表由应用维护，使用工具返回的最新状态，不从旧聊天结果推断当前有效结果。

## 适用范围和参数

仅支持墙高小于 5 m、干燥、水平无黏性填土、光滑直立墙背、斜前缘梯形或矩形墙、水平基底和非地震条件，按每延米墙长计算。可输入均布附加荷载。地下水、地震、黏性土、倾斜填土超出范围，应明确告知并停止按本模型计算；本轮没有新增这些工况的输入字段或程序化识别。

| 字段 | 含义与单位 |
|---|---|
| height_m | 墙高 H，m |
| base_width_m | 墙底宽 B，m |
| top_width_m | 墙顶宽 t，m |
| soil_unit_weight_kn_m3 | 填土重度 γ，kN/m³ |
| friction_angle_deg | 填土内摩擦角 φ，° |
| wall_unit_weight_kn_m3 | 墙体重度 γw，kN/m³ |
| base_friction_coefficient | 基底摩擦系数 μ |
| surcharge_kpa | 均布附加荷载 q，kPa；无附加荷载也须明确保存 0 |

## 工作流程

1. 调用 set_parameters 保存用户明确给出的参数，缺少条件就追问，不猜测。矩形可设置 wall_shape=rectangle 并按 B=t 处理。
2. 可以独立调用 validate_parameters 检查完整性、范围和几何关系；“通过当前输入规则检查”不等于设计合格。
3. 需要数值时调用 calculate_design；它会自行校验，不要求先调用校验工具，也没有新增强制确认步骤。
4. 解释时读取 get_current_result。所有工程数值、公式和已完成项目以工具证据为准；修改参数后旧结果和候选失效。
5. 需要调整时调用 compare_designs。用户明确锁定底宽或顶宽时，放入 fixed_dimensions。候选不会修改当前方案。
6. 用户同意后调用 apply_option，用返回候选的 index 选用并重算。用户只说“试一下”且未指定编号时用 1。无候选就说明搜索范围内无解，不编造候选。
7. 可通过 list_cases 和 load_case 复用案例参数；载入不自动计算。保存仍由网页按钮完成，没有聊天保存工具。

## 计算与比选边界

用户明确授权连续试算时，若需要更新参数并立即计算，可在同一轮依次调用 set_parameters、calculate_design，减少逐轮等待。每次改参后必须重算，未重算不得引用旧结果代表当前方案。

compare_designs 的内置筛选仅包含抗滑、抗倾覆及基底全接触，不包含用户自定义的额外限值（如“基底最大压力小于 60 kPa”）。必须使用实际工具结果逐项检查额外要求，不能把默认教学筛选通过视为满足所有条件。运行轮数有上限，达到上限时应明确说明尚未完成的核算与下一步，不承诺无限循环或一定存在可行解。

采用朗肯主动土压力简化模型。抗滑 1.30、抗倾覆 1.60 是沿用的教学对照值，基底压力为静力估算。几何比选在 0.1 m 网格搜索 B/t，以两个系数及基底全接触筛选，墙体自重用于用量比较，不是实际造价优化。顶宽搜索下限通常 0.3 m，是搜索设置而非规范构造下限。

原几何搜索允许探索梯形或矩形候选，当前矩形标记不构成搜索墙型锁定。选用后墙型按实际尺寸更新；若用户要求严格限定矩形，应说明当前比选没有此约束，不能声称已保持矩形。

地基承载力、沉降、整体稳定、墙身强度、构造、排水和实际造价未验算。不得将教学初算称为施工设计或完整规范符合性结论。需要标准摘要时先读取 standards skill。
